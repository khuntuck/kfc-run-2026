ตรวจสอบรหัสเข้าร่วมกิจกรรม

KFC Virtual Run 2026 เพื่อสนับสนุนโอกาสทางการศึกษาและอาชีพให้เด็กๆ

*กรอกอย่างใดอย่างหนึ่งเพื่อตรวจสอบสิทธิ์ของท่าน

เงื่อนไขและหมายเหตุการรับสิทธิ์

  • ร่วมบริจาคให้ โครงการ KFC Bucket search ผ่านเทใจดอทคอม (วันนี้ - 25 พฤศจิกายน 2569)
  • ทุกการบริจาค 590 บาท จะได้รับโค้ดลงทะเบียนกิจกรรมและรับของที่ระลึกฟรี โดยไม่มีค่าใช้จ่าย
  • สามารถใช้ Code ลงทะเบียนได้ถึงวันที่ 30 พฤศจิกายน 2569
  • Code จะตัดรอบส่งทุกวันอาทิตย์ และอัปเดตเข้าระบบภายในวันจันทร์
